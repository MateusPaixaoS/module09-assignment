# Module 9 – Introduction to Data Analysis with Pandas

This repository contains my work for Module 9 of the course.

## Project Overview

This project performs a **quarterly sales analysis** for GlobalTech, a multinational electronics retailer. It loads a simulated CSV dataset and uses Pandas to explore, filter, group, and summarize sales data across multiple regions and product categories.

## Files Included

- `module09-assignment.py` – Main Python script containing data loading, exploration, filtering, grouping, and the final business report.

## What I Practiced

- Loading and exploring a dataset with Pandas (`head()`, `info()`, `describe()`, `shape`).
- Selecting specific columns and performing calculations (totals, averages).
- Filtering rows using single and compound conditions.
- Grouping data with `groupby()` to compare regions and categories.
- Identifying missing values and understanding their impact on analysis.
- Drawing business insights and writing actionable recommendations from data.
